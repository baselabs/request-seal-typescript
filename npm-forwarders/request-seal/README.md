# request-seal

Use [`@request-seal/core`](https://www.npmjs.com/package/@request-seal/core) directly:

```bash
npm install @request-seal/core
```

This package only re-exports `@request-seal/core`, so that this name leads to the same project. It adds no code of its own.

It accepts any newer version of `@request-seal/core`. If you need stability, depend on the scoped package and
commit a lockfile. This package is published by hand and carries no provenance attestation; the scoped package
is where releases and attestations live.
