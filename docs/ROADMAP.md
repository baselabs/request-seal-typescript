# @request-seal/core roadmap

`@request-seal/core` is the zero-dependency TypeScript implementation of RequestSeal: HTTP Message Signatures (RFC 9421), content digests, Web Bot Auth, compact JOSE, discovery, replay protection and key custody on WebCrypto, for Node, Deno, Bun and browsers. Version 0.5.0 passes the RequestSeal for Elixir 1.0.0 corpus under one strict gate and exchanges live output with the published Hex package. The objective of this roadmap is native parity with RequestSeal for Elixir 2.0 in release 0.6.0. Future outcomes are ordered by dependency; decisions are in the records under `docs/adr`, starting with [0013](adr/0013-native-parity-on-the-2-0-corpus.md).
